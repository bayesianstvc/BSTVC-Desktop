PART 1Meet BSTVC V2

1  What BSTVC answers — shown with a real result

An ordinary regression gives each factor one coefficient, as if it worked the same way everywhere and every year. BSTVC lets that coefficient differ by area and by time point, so it answers three questions:

Where
How strong each factor is, and in which direction, in every area (spatial coefficients).
When
At which time points each factor acts more or less strongly than usual (temporal coefficients).
Which matters most
Each factor’s share of the spatiotemporal variation in the outcome, split into a spatial and a temporal part (STVPI).

Here are real results from case 1 (under-five mortality in 48 African countries, 2000–2020). Each figure answers one question:

Urbanisation relates to child mortality very differently from one country to the next, while the relationship barely changed over 20 years — so policy should be tailored by place. BSTVC computes and maps conclusions like this directly from your data.

Concept card · Local regression coefficientthe core of BSTVC
In one line
A regression coefficient says how much Y changes when X changes; BSTVC estimates one for every area and every time point — a “local” coefficient.
Analogy
The same rainfall (X) raises rivers more in the mountains than on the plains, and more in the wet season than the dry season. “How much the river rises” varies by place and season.
Why it matters
A single global coefficient averages away the fact that a factor matters a lot in some places and hardly at all in others, which leads to one-size-fits-all policy.
How to use it
Look at two tables: space.coefficients (by area) and time.coefficients (by time point). The full effect in one area at one time = its spatial coefficient + that time point’s temporal coefficient.
Say it to others
“BSTVC tells you not only whether a factor matters, but where and when it matters more.”

Concept card · Reading V2 temporal coefficientsV2
In one line
A V2 temporal coefficient tells you how much stronger or weaker a factor is at this time point than its average over the whole study period.
Analogy
Like a weather report saying “2 °C above the long-term average” (an anomaly) rather than “30 °C today”.
Why it matters
The zero line in a temporal-coefficient plot is the period average. Reading this reference correctly stops you from mistaking “weaker than usual” for “no effect”.
How to use it
> 0: more positive than usual at this time point; < 0: more negative. For the full effect in one area in one year, add that area’s spatial coefficient and that year’s temporal coefficient (adding the means is fine).
Say it to others
“V2 temporal coefficients are anomalies: they tell you which years were stronger or weaker than usual.”
Advanced For V1 users: what else differs and what stays the same
  • Interface: the nine pages, buttons and parameters are the same as V1; the About page lists one contact address, bstvc.research@gmail.com; when no custom spatial matrix is uploaded, Data Input states that the default matrix will be used.
  • V1 and V2 temporal coefficients use different reference points, so do not compare the share of “intervals excluding 0” between versions.
  • BSVC (spatial only, case 5) gives identical results in both versions: it has no temporal coefficients, so this update does not affect it.
  • Unchanged: at least two explanatory variables are required; for binary and count models STVPI splits 100% among the factors only (there is no residual term); there is no exposure (offset) option.

For the methodology, see the published BSTVC papers (How to cite).

PART 2One workflow for every case

4  Prepare your data: five checks before you start

Most failed runs are data problems, not software problems. Get the data right before you open the software.

  1. Use a long table: one row = one area at one time point (area ID, time, Y, X1, X2…); no (area, time) pair may appear twice. Convert wide tables first.
  2. Write missing values as NA: not blanks, 0 or −999. Y may have gaps (the software returns fitted values you can use to fill them); keep missing X values to a minimum.
  3. Match the outcome type: continuous (positive values), binary (0/1 only), count (non-negative integers). A rate is not a count.
  4. Match the area ID: the table and the map attribute table need an ID field with the same name and type and the same values (the text “21” does not match the number 21).
  5. Load all map files: select .shp .dbf .shx .prj (and .cpg if present) together; note any islands without neighbours (cases 1, 2 and 6 have some).
Concept card · Long (panel) table
In one line
Each row is one area at one time point.
Analogy
Like a grade book where each row is “one student in one exam”, not one row per student with a column per exam.
Why it matters
The model looks at differences between areas and changes over time at once; the long layout keeps both dimensions explicit.
How to use it
Already long (cases 1, 4, 6) → go straight to Data Input; wide (cases 2, 3) → Data Conversion first; one year only (case 5) → BSVC.
Say it to others
“One row per area per time point — that is the standard layout for spatiotemporal models.”

Concept card · Standardizing explanatory variables
In one line
Express every X as “how many standard deviations above or below its mean”, so all X share one ruler.
Analogy
To compare whether height (cm) or weight (kg) matters more for performance, first express both as “standard deviations above average”.
Why it matters
Only then can coefficients be compared, and only then are STVPI percentages meaningful. Case 4 shows with real results how the percentages shift without standardization (see 4b).
How to use it
Choose “Yes”. A coefficient then means “the change in the outcome when X rises by one standard deviation”.
Say it to others
“To compare which factors matter more, standardize first.”
Concept card · Neighbours (QUEEN spatial weights)
In one line
Two areas that share an edge or a single corner are neighbours; neighbouring coefficients are assumed to be similar.
Analogy
A queen in chess moves straight and diagonally, so squares that only touch at a corner also count as adjacent.
Why it matters
“Near things are more alike”: the model borrows information between neighbours, which stabilises estimates for areas with little data.
How to use it
Keep the default. Islands without neighbours (Hainan, Madagascar, many island states) cannot borrow from neighbours — describe them separately rather than dropping them.
Say it to others
“By default, adjacent areas are assumed to behave alike; islands have no neighbours, so treat their results with extra care.”

7.3.1  The error with the original map, and how to fix it

If you load the unrepaired original_map\africa_countries.* in step A, Data Input and Data Check both succeed, but after Run Model the status line turns red:

  1. Read the message. Loop 0 is not valid: Edge 0 crosses edge 78 means a polygon boundary crosses itself. Neighbours are computed on the sphere, which rejects polygons that are invalid on the globe.
  2. Find the culprit. In R: sf::sf_use_s2(TRUE); which(!sf::st_is_valid(sf::st_read("africa_countries.shp"))) points to Sudan (SDN), which looks perfectly normal on a flat map.
  3. Repair and save a copy. Snap the coordinates to a 0.001° grid (about 100 m) and repair the geometry: all 48 polygons become valid with no isolated country. Save as africa_countries_v2.* and keep the original untouched.
  4. Start again with the new map: Data Input → Data Check → modeling completes normally.

Sudan’s border has a tiny “knot” that you cannot see on a flat map, but it trips up the software when neighbours are computed on a globe. Straighten the border, save a copy, and it works.

Tip. Before loading any new map, check it in R: sf::sf_use_s2(TRUE); all(sf::st_is_valid(sf::st_read("map.shp"))) must return TRUE.

Concept card · AUC (accuracy for binary outcomes)
In one line
Pick one province-month with an outbreak and one without at random: AUC is the probability that the model scores the first one higher.
Analogy
Asking the model to rank two students: AUC = 0.95 means it gets the order right 95 times out of 100.
Why it matters
R² does not suit 0/1 outcomes, and AUC does not depend on whether you set the cut-off at 0.5 or 0.3.
How to use it
0.5 = guessing, 0.7–0.8 acceptable, above 0.9 very good. It is computed on the fitted data, not on new data.
Say it to others
“An AUC of 0.94 means the model separates outbreak and non-outbreak province-months very well.”
Technical note: AUC is the area under the ROC curve, equal to the Mann–Whitney rank statistic; here it is computed from predict_y (fitted probability) against observed y in local.prediction.

Concept card · Model evaluation: DIC, WAIC, LS, eff and pd2
In one line
DIC and WAIC measure “good fit without excess complexity”, LS scores leave-one-out prediction; lower is better for all three. eff and pd2 are the complexity estimates of the two criteria.
Analogy
Two teachers grade the same exam with different marking schemes (DIC and WAIC), so their marks differ.
Why it matters
Together they describe the fit; on the same data and the same Y they let you compare models.
How to use it
Compare DIC with DIC and WAIC with WAIC, never DIC with WAIC; report all values in a supplementary table.
Say it to others
“DIC and WAIC are two different rulers: lower is better, and you only compare on the same data.”

Concept card · STVPI (spatiotemporal variance partitioning index)
In one line
Splits the spatiotemporal variation explained by the model into percentages by factor and into spatial and temporal parts, to show who contributes most.
Analogy
How much of the spread in a class’s grades comes from “different schools” (space) versus “different terms” (time), and which subject drives each.
Why it matters
A coefficient says how strong an effect is; STVPI says how much a factor weighs in the overall pattern — useful for identifying key drivers.
How to use it
Rank factors by space.time.X (factor total), then see whether it comes mainly from space.X or time.X. Binary and count models have no residual term; the percentages are shared among the covariates.
Say it to others
“STVPI tells you who the main players are, and whether they act mainly between areas or over time.”
Technical note: Song et al. (2022); Wan et al. (2022). A relative-contribution measure with 2.5%–97.5% posterior intervals.

12.6  Interpretation

  • Evaluation: DIC 14,157, WAIC 16,154 (different criteria, so different values are normal), R² = 0.967.

  • Island states: the map has many island states and small clusters without neighbours; they cannot borrow information from neighbours, so describe them separately.

Differences in healthy life expectancy are mostly differences between countries; in this model the effects of income, urbanisation and other factors vary a lot from country to country but changed little over 20 years.

Concept card · R² (and why it can be low or even negative)
In one line
R² = 1 − residual sum of squares / total sum of squares: how much better the model does than simply guessing the mean.
Analogy
To guess everyone’s height with no information, you guess the average; R² measures how much better your method is than that naive guess. Worse than the naive guess gives a negative R².
Why it matters
It shows at a glance whether fitted and observed values agree.
How to use it
Computed on observed units from predict_y against y in local.prediction; figure 7 of the plotting script draws it.
Say it to others
“An R² of 0.97 means the model reproduces 97% of the variation — in the data it was fitted to, not in the future.”

# =====================================================================================
#  run_case.R  -  one call draws the full set of core figures for one BSTVC / BSVC workbook
# = "zh" "en"
#  Usage: source("R/bstvc_plot_functions.R"); source("R/run_case.R"); run_case(cfg)   (see scripts/*.R)
#  Output: outputs/<id>/<lang>/  (300 dpi PNG + vector PDF; no titles or captions inside the figures)
# =====================================================================================
.cfg_lang <- function(cfg) {                      # pick the language-specific settings (fields ending in _en)
  lang <- if (is.null(cfg$lang)) "zh" else cfg$lang; bstvc_lang(lang)
  if (lang == "en") for (f in c("tlab", "pred_label", "time_labels", "map_note", "label_field", "short", "title"))
    if (!is.null(cfg[[paste0(f, "_en")]])) cfg[[f]] <- cfg[[paste0(f, "_en")]]
  if (lang == "en" && !is.null(cfg$label_col)) cfg$label_col <- NULL
  cfg$lang <- lang; cfg
}
.saver <- function(cfg) function(p, stem, w, h) {   # cfg$map_note: one line under every map figure (e.g. a disclaimer)
  if (!is.null(cfg$map_note) && grepl("fig03|fig04|fig08_prediction_maps|fig15|fig20", stem)) {
    note <- grid::textGrob(cfg$map_note, x = unit(2, "mm"), hjust = 0, gp = grid::gpar(fontfamily = BSTVC_FONT, fontsize = 6, col = "grey35"))
    p <- patchwork::wrap_elements(full = p) / patchwork::wrap_elements(full = note) + patchwork::plot_layout(heights = unit(c(1, 4), c("null", "mm"))); h <- h + 4 }
  save_pub(p, paste0(cfg$id, "_", stem), w, h, outdir = cfg$outdir)
}
.read_case <- function(cfg) {
  res <- read_bstvc(cfg$xlsx); if (cfg$lang == "en") res <- translate_res(res, cfg$var_en)
  map <- sf::st_read(cfg$shp, quiet = TRUE)
  if (!is.null(cfg$drop)) map <- map[!as.character(map[[cfg$key]]) %in% cfg$drop, ]
  map <- map[!duplicated(as.character(map[[cfg$key]])), ]
  bb <- sf::st_bbox(map); list(res = res, map = map, asp = unname((bb[4] - bb[2]) / (bb[3] - bb[1])))
}
run_case <- function(cfg) {
  stopifnot(file.exists(cfg$xlsx), file.exists(cfg$shp))
  cfg <- .cfg_lang(cfg)
  cfg$outdir <- file.path(if (is.null(cfg$outdir)) file.path("outputs", cfg$id) else cfg$outdir, cfg$lang)
  dir.create(cfg$outdir, showWarnings = FALSE, recursive = TRUE)
  R <- .read_case(cfg); res <- R$res; map <- R$map; st <- "nature"; fac <- res$factors; k <- if (is.null(cfg[["k"]])) 6 else cfg[["k"]]
  nc <- min(3, length(fac)); nr <- ceiling(length(fac) / nc)
  mapH <- function(nr, ncol, extra = 8, legend = 0) { pw <- (183 - 4) / ncol - legend; round(nr * (R$asp * pw + 9) + extra) }
  S <- .saver(cfg)
  cat("\n=== ", cfg$title, " [", cfg$lang, "] ===\n", sep = "")
  # 1 global model evaluation
  ev <- res$model.evaluation; cat(check_model_eval(ev), sep = "\n")
  write.csv(model_eval_table(ev), file.path(cfg$outdir, paste0(cfg$id, "_model_evaluation.csv")), row.names = FALSE)
  S(plot_model_card(ev), "fig01_model_evaluation", 183, 55)
  # 2 temporal coefficients (BSTVC only)
  if (!is.null(res$time.coefficients))
    S(plot_time_coef(res$time.coefficients, cfg$t0, cfg$tlab, ncol = nc), "fig02_time_coefficients", 183, 12 + 42 * nr)
  # 3 spatial coefficients (core): coefficient maps + direction-probability maps; 4 hot / cold spots
  sc <- res$space.coefficients
  labs_map <- if (!is.null(cfg$label_field)) setNames(as.character(map[[cfg$label_field]]), as.character(map[[cfg$key]])) else NULL
  if (isTRUE(cfg$no_maps)) {
    S(plot_space_coef_intervals(sc, cfg$key, fac, labs_map, ncol = nc), "fig03_spatial_coefficients", 183, 20 + 60 * nr)
  } else {
    S(plot_space_coef_maps(map, cfg$key, sc, fac, ncol = nc, k = k, standardized = cfg$standardized), "fig03_spatial_coefficients", 183, mapH(nr, nc, 6, legend = 17))
    S(plot_direction_prob_maps(map, cfg$key, sc, fac, ncol = nc), "fig03b_direction_probability", 183, mapH(nr, nc, 16))
    hs <- plot_hotspot_maps(map, cfg$key, sc, fac, ncol = nc)
    if (!is.null(hs)) S(hs, "fig04_hotspots_Gi_star", 183, mapH(nr, nc, 14))
  }
  # 5-6 STVPI
  sv <- read_stvpi(res)
  S(plot_stvpi_facets(sv, ncol = 2), "fig05_STVPI_faceted", 183, 40 + 10 * length(fac))
  if (any(grepl("^time\\.", sv$effect))) S(plot_stvpi_stacked(sv), "fig06_STVPI_stacked", 120, 18 + 6 * length(fac))
  # 7-8 fit and predictions
  lp <- res$local.prediction; typ <- cfg$type
  S(plot_prediction_accuracy(lp, typ, logaxes = isTRUE(cfg$logaxes)), "fig07_prediction_accuracy", 89, 80)
  if (isTRUE(cfg$no_maps) && !is.null(cfg$time_col)) {
    S(plot_prediction_tiles(lp, cfg$key, cfg$time_col, labs_map, legend_title = cfg$pred_label, time_labels = cfg$time_labels), "fig08_prediction_tiles", 140, 110)
  } else if (!is.null(cfg$time_col) && cfg$time_col %in% names(lp)) {
    tm <- cfg$pred_times; ncp <- min(3, length(tm))
    p <- plot_prediction_maps(map, cfg$key, lp, cfg$time_col, tm, "predict_y", ncol = ncp, legend_title = cfg$pred_label)
    if (!is.null(cfg$time_labels)) p$data$time <- factor(cfg$time_labels[as.character(p$data$time)], levels = cfg$time_labels[as.character(tm)])
    S(p, "fig08_prediction_maps", 183, mapH(ceiling(length(tm) / ncp), ncp, 18))
  } else {
    S(plot_map_classed(map, cfg$key, data.frame(key = lp[[cfg$key]], value = lp$predict_y), NULL, k = 7, legend_title = cfg$pred_label), "fig08_prediction_map", 120, round(R$asp * 95 + 10))
  }
  invisible(res)
}

17.1  Good habits

  1. Keep the program, data, maps and results in English-only paths.
  2. One folder per study: table, map and results together; never overwrite raw data, and give converted files new names.
  3. Start small: run with two or three complete X first, then add variables.
  4. Download all tables right after each run and note the settings next to them (Y, X and order, type, time, space, standardization, matrix, threads, software version, date) — the workbook does not store them.
