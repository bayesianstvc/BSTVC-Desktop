# BSTVC V1/V2：可复现的后估计区间实验

本包只含既有导出结果的必要数值摘要和新编写的 R 后估计分析代码，不含原始 XLSX、观测数据、地图、拟合对象、私有算法或模型拟合代码。运行脚本不会训练、重拟合、抽取后验样本或联网。

需要 R 4.2 或以上版本。只使用随 R 提供的 base、graphics、grDevices、stats 和 utils，不需安装第三方包。PNG 输出需要当前 R 的 Cairo 支持；Windows 的本次运行环境已具备该支持。图中采用英文以保证离线字体可移植性；变量中英文对照会写入结果目录。

把本包完整解压，在该目录运行：

```r
Rscript --vanilla reproduce_analysis.R
```

也可显式指定输入和输出目录：

```r
Rscript --vanilla reproduce_analysis.R . ./my-results
```

结果默认写入 `results/`。脚本会重建所有 CSV、JSON、HTML 内容片段以及五组 300 dpi PNG / 矢量 PDF 图形。脚本不会覆盖输入数据。

## 数据范围与溯源

三个案例来自中文手册 V03 参考结果和对应 V2 GUI 导出：

- `c6`：全球健康预期寿命（HALE），12 个协变量，177 个地区，21 个年份；采用原中文 V03 的 20 线程基线。
- `c2`：中国 COVID-19，6 个协变量，31 个地区，12 个月。
- `c3`：美国乙肝，4 个协变量，5 个地区，12 个年份。

V1 输入是 `Case6_HALE_12X_all_result_tables.xlsx`、`Case2_COVID_all_result_tables.xlsx` 和 `Case3_HBV_all_result_tables.xlsx`；V2 输入为相应文件名附加 `_V2` 的 GUI 导出。6X quick-test 不在本包范围。工作簿、既有 lincomb 与既有重建分量的文件名、大小和 SHA-256 记录在 `source-provenance.json`；该文件不含原机器绝对路径。

本包的数字是上述既有结果的快照。来源工作簿没有一并公开；哈希支持日后核对来源身份，不证明源拟合的科学有效性。

## 七个必要输入 CSV

| 文件 | 内容与用途 |
| --- | --- |
| `component_quantiles.csv` | 两版时间/空间分量的点估计和五个分位数；复算 95%、50% 宽度和 V2 跨零状态 |
| `fitted_mean_quantiles.csv` | 按地区与时间标识的软件导出拟合量分位数，以及原导出 Y 是否缺失；不包含 Y 观测值；历史文件名保留 |
| `variables.csv` | 每个案例的中文变量与 X01 等编码 |
| `lincomb_quantiles.csv` | 既有独立重建的总系数均值与 95% 上下限；HALE 只覆盖首、中、末三年 |
| `refit_component_quantiles.csv` | 同一既有重建的分量均值及 95% 上下限；检验均值相加恒等和端点相加错误示范 |
| `gui_evaluation.csv` | GUI 的 DIC、有效参数数、LS、WAIC 及导出指标；用于核对辅助重建与原拟合的差异 |
| `refit_evaluation.csv` | 既有重建的对应指标，NA 保留原样 |

空间总系数 CSV 原本只有 `space_index`。本包通过导出工作簿的空间 ID 列建立地区标识，提取时验证同工作簿所有变量的 ID 列一致。公开脚本使用地区、时间与变量键，不按表格行号配对。

## 严格配对与计算定义

GUI 分量按 `case + part + variable + region + time_index` 配对；软件导出的拟合量按 `case + region + time_value + scale` 配对；既有总系数按 `case + variable + region + space_index + time_index` 配对。代码对两版唯一性、完整键集合和预期条目数进行断言；发现重复或漏配即停止，不会聚合重复键、做多对多连接或静默删除未配对行。

95% 宽度为 `q975 - q025`，50% 宽度为 `q75 - q25`。逐项宽度比为 `V2宽度 / V1宽度`。中位收窄百分比为 `100 × (1 - median(逐项宽度比))`；它不是“两版宽度中位数之比”，也不是按地区或变量等权后再平均。每个变量的精确统计单独输出。

只有两版均为有限正宽度时才定义比值。所有行继续保留；无效项的比值为 `NA`，并写入单独明细与计数。没有填补、零填充或构造分位数。

HALE 原导出有 273 项 Y 缺失，其中 253 项两版导出分位数都为 1，宽度为 0，因而比值无效；其余 20 项仍有正宽度。这里保留的是原导出异常，不将其改写为精确预测或科学上可信的零不确定性。

## 五项实验与解释边界

1. **逐项区间比分布和例外**：分别从原分位数复算 95% 与 50% 区间。HALE 空间 2124 项中有 76 项变宽；两级宽度比近乎一致，不构成独立校准证据。
2. **分量、总系数、导出拟合量区别**：三类统计对象分开显示。总系数来自既有独立重建，无法代表 GUI 原拟合的数值全同复现。HALE 总系数仅覆盖 2000、2010 和 2020 年，共 `12 × 177 × 3 = 6372` 项。
3. **边际端点相加错误示范**：在同一个既有重建中比较 `(空间边际宽度 + 时间边际宽度) / lincomb总系数宽度`。分子不构成总系数的 95% 可信区间。均值相加的最大绝对误差约 `9.144e-13` 只验证重建内部的索引与均值恒等，不验证源模型、采样、相关矩阵或与 GUI 的全同。
4. **V2 自身的跨零状态**：输出高于零、低于零和包含零。没有多重比较调整，不把它称为 V1/V2 显著性改变检验。中心化定义不同，分量位置不能直接做这种跨版本解释。
5. **导出拟合量极端项**：COVID 海南第 12 月的 95% 宽度由约 `7.659e-11` 变为 `0.539087`，宽度比约 `7.039e9`。完整动态范围单独绘出，不用中位数掩盖极端项。HALE 253 个零宽度行全部保留。

时间/空间分量均有 50% 分位数；既有总系数 CSV 只有 95% 上下限，因此没有生成总系数的 50% 区间，也没有套用正态近似。

统一术语为“软件导出的拟合量后验区间”；代码、文件和既有图中的 `fitted_mean` / `Fitted mean` 是保留的历史标识，不意味着所有案例都等于一般意义上的 `E[Y]`。HALE 使用导出表的反变换分位数，其中 `exp(mu)` 一般不能直接当作 `E[Y]`；本次不补入对数正态均值修正或观测误差。COVID 使用概率尺度，HBV 使用期望计数尺度。这些不是未来观测的后验预测区间；不能据此声称样本外预测精度、覆盖率或校准改善。

V1/V2 分量中心化不同。收窄本身不证明参数恢复、准确性、收敛、覆盖率、因果识别或整个软件的全面改善。

## V2 时间中心化的补充数值核查

`v2_time_centering_check.csv` 对三个案例共 22 个变量分别计算：V2 时间分量的 posterior mean 在全部时间点上的算术平均、其绝对值、各时间点均值之和、有限值条目数与最大绝对均值。HALE 每个变量使用 21 个年份，COVID 与 HBV 每个变量使用 12 个时间点；没有时间加权或重新中心化。

22 项算术平均的最大绝对值约为 `5.6841131e-9`，均小于本次明示的数值容差 `1e-8`。CSV 保留实际残差，而非把结果改写为精确 0；该容差只是针对导出数值的近零检查口径。此结果支持所导出均值与 V2 时间中心化口径相容，**不是收敛诊断、后验有效样本量、覆盖率、参数准确性或源模型全部约束均已验证的证据**。

## 来源报告中需要校正的表述

既有辅助重建并非对所有案例都满足“DIC 与 GUI 差小于 0.2”。HALE V1 重建 DIC 为约 14070.94610，GUI 为约 14068.84342，差约 +2.10268；HALE V1/V2 重建 LS 均为 NA。本脚本逐案例、逐版本输出所有可核对的指标差异，不将这些差异归因于线程或其他未经检验的原因。
