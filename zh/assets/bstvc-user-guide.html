PART 1认识 BSTVC V2

1  BSTVC 能回答什么：用一个真实结果来看

普通回归只给每个因素一个系数，好像它在所有地方、所有年份作用都一样。BSTVC 让这个系数在每个地区、每个时点都可以不一样，于是能回答三个问题：

在哪里
每个因素在每个地区的作用大小和方向（空间系数）。
什么时候
每个因素的作用在哪些时点比平时强、哪些时点弱（时间系数）。
谁更重要
各因素对结局时空差异的贡献百分比，以及主要来自空间还是时间（STVPI）。

下面是案例 1（非洲 48 国五岁以下儿童死亡率，2000–2020）的真实结果，一张图回答一个问题：

同样是城市化，在不同国家和儿童死亡率的关系很不一样；而这种关系 20 年里变化不大。所以政策重点是“因地制宜”。BSTVC 就是把这种结论从数据里直接算出来、画出来。

概念卡 · 局部回归系数BSTVC 回答的核心问题
一句话
回归系数 = X 变化时 Y 跟着变多少；BSTVC 给每个地区、每个时点各算一个，叫“局部回归系数”。
打个比方
同样下一场雨（X），山区的河水涨得多，平原涨得少；雨季涨得多，旱季涨得少。“涨多少”随地点、季节而变。
为什么要用
只给一个全局系数，会把“有的地方作用强、有的地方几乎没作用”平均掉，政策就会一刀切。
怎么用
看两张表：space.coefficients（各地区）和 time.coefficients（各时点）。某地某时的完整作用 = 空间系数 + 该时点的时间系数。
讲给别人听
“BSTVC 不只告诉你某个因素重不重要，还告诉你它在哪里、什么时候更重要。”

概念卡 · V2 的时间系数怎么读V2
一句话
V2 的时间系数表示：这个时点，因素的作用比整个研究时期的平均水平强多少或弱多少。
打个比方
像天气预报说“今天比常年平均高 2℃”（距平），而不是“今天 30℃”。
为什么要知道
时间系数图里的 0 线就是“时期平均”；读对了参照，才不会把“比平时弱”误读成“没有作用”。
怎么用
时间系数 > 0：这个时点作用比平时更正向；< 0：更负向。想知道某地某年的完整作用，把这个地区的空间系数和这一年的时间系数相加（均值相加即可）。
讲给别人听
“V2 的时间系数是距平，告诉你哪一年比平常更强、哪一年更弱。”
进阶 V1 老用户：还有哪些地方不一样、哪些没变

PART 2一套通用流程

4  准备数据：动手前检查五件事

大多数运行失败是数据问题，不是软件问题。打开软件之前先把数据整理对。

  1. 表格是长表：一行 = 一个地区在一个时点（地区 ID、时间、Y、X1、X2…）；同一个（地区, 时间）不能出现两次。宽表先做“数据转换”。
  2. 缺失写 NA：不要用空格、0、−999。Y 可以有缺失（软件会给出拟合值，可用来补缺）；X 尽量少缺失。
  3. 结局类型对得上：连续型（正数）、二分类（只有 0/1）、计数型（非负整数）。“率”不是计数。
  4. 空间 ID 对得上：表格和地图属性表里要有一个名字和类型都相同的 ID 字段，取值一致（文本“21”和数字 21 对不上）。
  5. 地图文件齐全：.shp .dbf .shx .prj（有 .cpg 也一起选）一次全选；没有邻居的岛屿要心中有数（案例 1、2、6 都有）。
概念卡 · 长表（面板数据）
一句话
每一行是“一个地区在一个时点”的观测。
打个比方
像成绩登记表：一行是“某个学生在某次考试”，而不是一个学生一行、每次考试各占一列。
为什么要用
模型要同时看“地区之间的差别”和“时间上的变化”，长表能把两个维度都摆清楚。
怎么用
已经是长表（案例 1、4、6）→ 直接“数据输入”；是宽表（案例 2、3）→ 先“数据转换”；只有一年（案例 5）→ 用 BSVC。
讲给别人听
“一行一个地区一个时间，这是时空模型的标准格式。”

4.1  九个建模参数，怎么选

参数推荐常见错误
数据来源数据检查提示“已完成自动重排”→ 选检查后数据重排后仍选原始数据：结果被放到错误的地区上，而且不报错
响应变量 Y你的结局把率、人数、病例数混用
解释变量 X按研究问题选，至少 2 个；记下顺序把 ID、时间、Code / timeID / spaceID 选进去
响应类型连续型 / 二分类 / 计数型（见上一章表格）默认是连续型，二分类、计数忘了改
时间字段年份、月份等选成了 X
空间字段与地图同名的 ID 字段选了名称字段而不是代码字段
解释变量标准化是标准化后把系数说成“X 增加 1 个原始单位”
空间权重矩阵默认 QUEEN（共享边或角就算邻居）换自定义矩阵却不核对 ID 顺序
线程数20以为越多越快（超过约 20 不再加速）
概念卡 · 解释变量标准化
一句话
把每个 X 换成“比平均高（低）几个标准差”，让所有 X 用同一把尺子。
打个比方
比较身高（厘米）和体重（公斤）谁对成绩影响大，要先都换成“比平均高几个标准差”，才放得到一起比。
为什么要用
系数之间才能比大小，STVPI 的“贡献百分比”才有意义。案例 4 用真实结果展示了不标准化时百分比会怎么变（见 4b）。
怎么用
选“是”。系数的意思变成“X 增加 1 个标准差，结局跟着变多少”。
讲给别人听
“要比较几个因素谁更重要，先标准化。”
概念卡 · 邻居（QUEEN 空间权重矩阵）
一句话
两个地区只要共享一条边或一个角，就算邻居；邻居之间的系数被认为更相似。
打个比方
国际象棋里的皇后（Queen）能横竖斜走，所以“挨着角”的格子也算相邻。
为什么要用
“近的东西更相似”：模型据此在相邻地区之间互相借用信息，地区数据少时估计更稳。
怎么用
用默认即可。没有邻居的岛屿（海南、马达加斯加、很多岛国）借不到邻居的信息，解读时单独说明，不要为此删掉研究对象。
讲给别人听
“模型默认挨着的地区作用更像，岛屿没有邻居，结论要更谨慎。”

7.2  步骤 A：数据输入

  1. 点左侧数据输入。在“建模表格数据（CSV / Excel）”下点 Browse…，选 africa_u5mr_panel_zh.csv（1）。这张表已经是“一行一国一年”的长表，可以直接载入，不需要数据转换。
  2. 在“建模地图数据（shapefile）”下点 Browse…，按住 Shift 一次选中 africa_countries_v2 的 4 个文件（2），框里显示“4 files”。shapefile 是一组文件：.shp 存形状、.dbf 存属性（里面有 iso3）、.shx 是索引、.prj 是坐标系。少一个就读不出来。这份地图没有 .cpg（属性表全是英文），所以是 4 个。
  3. “空间权重矩阵”留空（3），点读取并验证输入（4）。留空 = 用默认的 QUEEN 邻接矩阵，绝大多数研究用它就够了。
  4. 看左下三条消息（5）：[OK] 数据读取成功！、[OK] 地图读取成功！、[INFO] 未上传自定义矩阵…；看右上三个方块（6）：数据行数 1008、数据列数 10、地图单元数 48。1008 = 48 × 21，说明每个国家每年都有一行；48 与地图单元数一致，说明表格和地图覆盖同一批国家。
技巧。点右侧“地图”标签可以预览地图（下图），确认多边形都读进来了；“数据表”标签里能看到每个字段的类型和缺失比例。

7.3  步骤 B：数据检查——以及一张需要修复的地图

  1. 点数据检查，检查模式保持 BSTVC 时空面板（1）。
  2. 时间字段选 年份（2），空间字段选 iso3（3），点运行检查（4）。字段框可以直接打字搜索：点一下框，输入“年”，回车。
  3. 读结果卡片（5）：标题 已完成自动重排。灰色日志里先有一行 Error: The number of spatial units per year…，最后是 Success——这是正常的检查过程信息。表格是按 iso3 字母排的，地图是按 Natural Earth 的顺序排的，软件把表格重排成地图的顺序。
  4. 记住：下一步数据来源要选检查后数据。可选：用（6）下载检查后的表格留档。

7.3.1  第一次用原始地图时的报错，以及怎么修

如果在步骤 A 载入的是未修复的 original_map\africa_countries.*，数据输入和数据检查都会成功，但点“运行模型”后状态行出现红字：

  1. 读懂报错。Loop 0 is not valid: Edge 0 crosses edge 78 的意思是：某个多边形的边界自己和自己交叉了。软件构建邻接关系时使用球面几何，会拒绝这种“在球面上无效”的多边形。
  2. 找出是哪一个。在 R 里运行 sf::sf_use_s2(TRUE); which(!sf::st_is_valid(sf::st_read("africa_countries.shp")))，结果指向苏丹（SDN）。它在平面地图上看起来完全正常。
  3. 修复并另存。把坐标吸附到 0.001° 网格（约 100 米）再修复几何，48 个多边形全部有效、没有孤立国家；存成新文件 africa_countries_v2.*，原图保留不动。
  4. 用新地图重来：重新数据输入 → 数据检查 → 建模，正常完成。

地图上苏丹的边界线在某处“打了个结”。平面上看不出来，但软件把地图放到地球仪上算邻居时卡住了。把边界理顺、另存一份，就好了。

技巧。以后载入任何新地图前，先在 R 里自检一句：sf::sf_use_s2(TRUE); all(sf::st_is_valid(sf::st_read("map.shp"))) 必须是 TRUE。

7.4  步骤 C：BSTVC 建模

  1. 数据来源选检查后数据（1）。上一步提示已重排；选“原始数据”会让结果对错国家，而且不会报错。
  2. 响应变量 Y：五岁以下儿童死亡率（2）。
  3. 解释变量 X：依次输入并回车 城市人口比例、PM25暴露、人口百万（3）。先用 3 个没有缺失的 X 跑通，再考虑加变量；不要选 iso3、年份、Code、timeID、spaceID。
  4. 响应类型：连续型 continuous（4）。死亡率是正的连续数。
  5. 时间字段 年份（5），空间字段 iso3（6）。
  6. 解释变量标准化：是（7）；空间权重矩阵：默认 QUEEN-B（8）；线程数：20（9）。
  7. 点运行模型（10）。页面变灰、显示“贝叶斯 STVC/SVC 模型正在运行，请稍候……”，本例 < 15 秒 完成。运行时不要点别的页面；窗口灰着就是在算。

  • 先看评价：DIC 8,369、WAIC 8,371；拟合值与观测值 R² = 0.79。
  • 谁更重要：STVPI 中空间部分占 98.3%，说明三个因素的作用主要是国家之间不同，而不是 2000–2020 年间在变。最重要的是 人口百万。

概念卡 · AUC（二分类的预测精度）
一句话
随便挑一个“发生了疫情”的省月和一个“没发生”的省月，模型给前者打的分更高的概率。
打个比方
像让模型给两个学生排名次：AUC = 0.95 表示 100 次里有 95 次排对了谁考得更好。
为什么要用
二分类结局不能用 R²；AUC 不受“阈值取 0.5 还是 0.3”的影响。
怎么用
0.5 = 瞎猜，0.7–0.8 可接受，0.9 以上很好。注意它是在同一批数据上算的（训练拟合），不是对新数据的预测能力。
讲给别人听
“AUC 0.94，说明模型很会区分发生和没发生疫情的省份月份。”
专业注释：AUC = ROC 曲线下面积，等于 Mann–Whitney 秩统计量；本手册用 local.prediction 的 predict_y（后验均值概率）对观测 y 计算。

概念卡 · 模型评价：DIC、WAIC、LS 与 eff、pd2
一句话
DIC、WAIC 衡量“拟合得好又不过分复杂”，LS 衡量逐个留出时的预测得分，三者都是越小越好；eff、pd2 是两种算法各自给出的模型复杂度。
打个比方
两位老师用不同的评分细则给同一份卷子打分（DIC 与 WAIC），分数不同很正常。
为什么要看
它们一起描述这次拟合；在同一份数据、同一个 Y 上，可以用来比较几个模型。
怎么用
DIC 对 DIC、WAIC 对 WAIC，不要拿 DIC 去比 WAIC；全部数字如实写进论文附表。
讲给别人听
“DIC 和 WAIC 是两把尺子，各量各的；越小越好，只在同一份数据上比。”

11.1  案例卡

概念卡 · BSVC 与 BSTVC 的区别
一句话
BSVC 只让系数随地区变（一个时点）；BSTVC 让系数同时随地区和时间变（多个时点）。
打个比方
BSVC 是一张照片，BSTVC 是一段录像。
为什么要用
很多数据只有一次普查或一年的截面，这时用 BSVC；硬套 BSTVC 没有时间信息可用。
怎么用
数据检查选“BSVC 空间截面”（只填空间字段）→ 左侧点“BSVC 空间建模” → 参数里没有时间字段 → 结果 5 张表（没有 time.coefficients）。
讲给别人听
“只有一年的数据用 BSVC，看的是各地区的差别。”
提示：每个地区只有一个观测，信息比多年数据少得多，系数区间通常较宽；STVPI 只有空间部分。

11.2  步骤 A、B：数据输入与“截面”检查

  1. 数据输入：载入截面表格和地图 → 核对 49 行、10 列、49 个地图单元。
  2. 数据检查：检查模式选 BSVC 空间截面（1），时间字段框消失；空间字段 stusps（3）→ 运行检查（4）→ 已完成自动重排（5）。

11.3  步骤 C：BSVC 建模

点左侧 BSVC 空间建模：检查后数据（1）· Y 高自杀率（2）· 四个 X（3）· 二分类（4）· 空间 stusps（6）· 标准化 = 是（7）· QUEEN-B（8）· 线程 20（9）→ 运行模型（10），< 15 秒 完成。

预期结果。DIC 48.9 · WAIC 50.2 · LS 0.519 · eff 4.49 · pd2 5.03 · AUC 0.898（49 个地区）。STVPI（只有空间部分）：药物中毒年龄调整死亡率 22.7%、贫困率 21.0%、人口百万 18.5%、家庭收入中位数千美元 18.3%。

11.4  结果解读

  • BSVC 没有时间系数，这次 V2 更新不涉及它；本例 V1 与 V2 的结果几乎相同（DIC 相差 0.00）。
  • 每个地区只有一个 0/1 观测，四个因子的 STVPI 区间都很宽（约 2–75%），不能据此给因子排名；AUC 说明模型能较好地区分高、低两组地区。

只有一年、每州一个“高或不高”的标签，模型能看出大致的地区差异，但说不准哪个因素最重要。

概念卡 · STVPI（时空方差分解指数）
一句话
把模型解释的“时空变异”按因子、按“空间部分 / 时间部分”分成百分比，看谁贡献最大。
打个比方
一个班成绩的高低差异，有多少来自“学校不同”（空间）、多少来自“学期不同”（时间），又各由哪门课贡献。
为什么要用
系数告诉你“作用多大”，STVPI 告诉你“这个因素在整体格局里占多重”，用来识别关键驱动因素。
怎么用
看 space.time.X（因子合计）排序；再看它主要来自 space.X 还是 time.X。二分类和计数模型没有残差项，百分比只在协变量之间分配。
讲给别人听
“STVPI 说的是‘谁是主角’，以及它主要是在地区之间起作用，还是在时间上起作用。”
专业注释：Song 等（2022）、Wan 等（2022）。相对贡献指标，带后验 2.5%–97.5% 区间。

12.6  结果解读

  • 评价：DIC 14,163、WAIC 16,154（两种算法，数值不同属正常），R² = 0.967。
  • 谁更重要：人均国民收入 的贡献最大；空间部分占 99.4%：因素的作用主要体现在国家之间，21 年里变化很小。
  • 岛国：地图上有很多没有邻居的岛国和小连通块，它们借不到邻居的信息，解读时单独说明。

各国健康寿命的差别，主要来自国与国之间的差别；在这个模型里，收入、城市化等因素的作用在各国差异很大，但 20 年间变化不大。

12.7  为什么要用 12 个变量：少变量试跑与正式运行

运行X 个数用时DICR²
少变量试跑6（孕产妇死亡率、归一化植被指数、高体质指数、维生素A缺乏、PM25年均浓度、城市人口比例）≈ 54 秒22,2840.575

变量太少时，模型解释不了各国的水平差异，R² 明显偏低。经验法则：先用少量 X 快速确认流程能跑通，正式运行用全部有研究意义的 X、线程 20。R² 是同一数据上的拟合，不等于对新数据的预测能力。

概念卡 · R²（为什么可能很低甚至为负）
一句话
R² = 1 − 误差平方和 / 总平方和：模型比“直接用平均值猜”好多少。
打个比方
猜全班身高，什么都不知道就猜平均身高；R² 衡量你的方法比这个“傻办法”好多少。比傻办法还差，R² 就是负的。
为什么要用
直观地检查预测值和观测值吻不吻合。
怎么用
在有观测的单元上，用 local.prediction 的 predict_y 对 y 计算；出图脚本的图 7 自动画出。
讲给别人听
“R² 0.97 表示模型复现了 97% 的差异；但这是对已有数据的拟合，不是对未来的预测。”

14  进阶：局部系数的“类 SHAP”图（可选）

这是锦上添花的可选模块，核心仍是上一章的空间系数地图。每个地区、每个时点都有自己的局部回归系数，这和机器学习里 SHAP 给“每个样本、每个特征”一个解释值的思路一样，所以可以借用 SHAP 那一整套图，从更多角度挖掘结果。

概念卡 · 局部系数与 SHAP为什么能借用
一句话
SHAP 告诉你“这个样本里每个特征推高或拉低了预测多少”；BSTVC 的局部系数告诉你“这个地区、这个时点每个因素的作用多大”。两者都是“局部解释”。
打个比方
全班的平均分只有一个数；局部解释是给每个学生都写一份“哪门课拉了分、哪门课加了分”的成绩分析。
为什么要用
地图一次只能看一个因素；类 SHAP 图能把所有因素、所有地区放在一张图里比较，找出主导因素、作用模式和地区类型。
怎么用
运行 run_local_coef(cfg)（案例脚本里已经写好）；需要建模用的数据表（cfg 里的 data），用来取每个地区的 X 值。
讲给别人听
“BSTVC 的局部系数天生就是可解释的，可以像 SHAP 一样一张图看清每个地区由什么因素驱动。”
说明：“贡献” = 局部系数（空间系数 + 该时点时间系数）× 该地区 X 的标准化值，表示“这个地区因为该因素偏离平均水平，结局被推高或拉低了多少”。
图回答什么怎么读
9 系数蜂群图每个因素的作用在地区之间差多少？每个点一个地区；横向越分散，地区差异越大；颜色 = 该地区 X 高低
10 平均作用强度总体上哪个因素作用最强？条越长作用越强（正负都算）；括号里是作用为正的地区占比
11 依赖图X 高的地方，作用是否更强？点 = 地区；黑线上升 = X 越高作用越正
12 贡献瀑布图某个地区的结局被哪些因素推高、拉低？红 = 推高，蓝 = 拉低，从上到下按贡献大小排列（默认展示拟合值最高和最低的两个地区）
13 地区 × 因素热图哪些地区的作用模式相似？红 = 该地区这个因素作用偏强；相邻行模式相近
14 局部系数时空热图最重要因素的作用在每个地区、每个时点怎样变化？横看随时间，竖看地区之间

18 决策图每个地区的结局是怎样一步步被推到最终位置的？每条线一个地区，在哪一层拐弯，哪个因素就让它与众不同

run_case.R：一个配置画出全部核心图
# =====================================================================================
#  run_case.R  -  one call draws the full set of core figures for one BSTVC / BSVC workbook
#  一次调用画出一份结果工作簿的全套核心图；cfg$lang = "zh" 或 "en"
#  Usage: source("R/bstvc_plot_functions.R"); source("R/run_case.R"); run_case(cfg)   (see scripts/*.R)
#  Output: outputs/<id>/<lang>/  (300 dpi PNG + vector PDF; no titles or captions inside the figures)
# =====================================================================================
.cfg_lang <- function(cfg) {                      # pick the language-specific settings (fields ending in _en)
  lang <- if (is.null(cfg$lang)) "zh" else cfg$lang; bstvc_lang(lang)
  if (lang == "en") for (f in c("tlab", "pred_label", "time_labels", "map_note", "label_field", "short", "title"))
    if (!is.null(cfg[[paste0(f, "_en")]])) cfg[[f]] <- cfg[[paste0(f, "_en")]]
  if (lang == "en" && !is.null(cfg$label_col)) cfg$label_col <- NULL
  cfg$lang <- lang; cfg
}
.saver <- function(cfg) function(p, stem, w, h) {   # cfg$map_note: one line under every map figure (e.g. a disclaimer)
  if (!is.null(cfg$map_note) && grepl("fig03|fig04|fig08_prediction_maps|fig15|fig20", stem)) {
    note <- grid::textGrob(cfg$map_note, x = unit(2, "mm"), hjust = 0, gp = grid::gpar(fontfamily = BSTVC_FONT, fontsize = 6, col = "grey35"))
    p <- patchwork::wrap_elements(full = p) / patchwork::wrap_elements(full = note) + patchwork::plot_layout(heights = unit(c(1, 4), c("null", "mm"))); h <- h + 4 }
  save_pub(p, paste0(cfg$id, "_", stem), w, h, outdir = cfg$outdir)
}
.read_case <- function(cfg) {
  res <- read_bstvc(cfg$xlsx); if (cfg$lang == "en") res <- translate_res(res, cfg$var_en)
  map <- sf::st_read(cfg$shp, quiet = TRUE)
  if (!is.null(cfg$drop)) map <- map[!as.character(map[[cfg$key]]) %in% cfg$drop, ]
  map <- map[!duplicated(as.character(map[[cfg$key]])), ]
  bb <- sf::st_bbox(map); list(res = res, map = map, asp = unname((bb[4] - bb[2]) / (bb[3] - bb[1])))
}
run_case <- function(cfg) {
  stopifnot(file.exists(cfg$xlsx), file.exists(cfg$shp))
  cfg <- .cfg_lang(cfg)
  cfg$outdir <- file.path(if (is.null(cfg$outdir)) file.path("outputs", cfg$id) else cfg$outdir, cfg$lang)
  dir.create(cfg$outdir, showWarnings = FALSE, recursive = TRUE)
  R <- .read_case(cfg); res <- R$res; map <- R$map; st <- "nature"; fac <- res$factors; k <- if (is.null(cfg[["k"]])) 6 else cfg[["k"]]
  nc <- min(3, length(fac)); nr <- ceiling(length(fac) / nc)
  mapH <- function(nr, ncol, extra = 8, legend = 0) { pw <- (183 - 4) / ncol - legend; round(nr * (R$asp * pw + 9) + extra) }
  S <- .saver(cfg)
  cat("\n=== ", cfg$title, " [", cfg$lang, "] ===\n", sep = "")
  # 1 global model evaluation
  ev <- res$model.evaluation; cat(check_model_eval(ev), sep = "\n")
  write.csv(model_eval_table(ev), file.path(cfg$outdir, paste0(cfg$id, "_model_evaluation.csv")), row.names = FALSE)
  S(plot_model_card(ev), "fig01_model_evaluation", 183, 55)
  # 2 temporal coefficients (BSTVC only)
  if (!is.null(res$time.coefficients))
    S(plot_time_coef(res$time.coefficients, cfg$t0, cfg$tlab, ncol = nc), "fig02_time_coefficients", 183, 12 + 42 * nr)
  # 3 spatial coefficients (core): coefficient maps + direction-probability maps; 4 hot / cold spots
  sc <- res$space.coefficients
  labs_map <- if (!is.null(cfg$label_field)) setNames(as.character(map[[cfg$label_field]]), as.character(map[[cfg$key]])) else NULL
  if (isTRUE(cfg$no_maps)) {
    S(plot_space_coef_intervals(sc, cfg$key, fac, labs_map, ncol = nc), "fig03_spatial_coefficients", 183, 20 + 60 * nr)
  } else {
    S(plot_space_coef_maps(map, cfg$key, sc, fac, ncol = nc, k = k, standardized = cfg$standardized), "fig03_spatial_coefficients", 183, mapH(nr, nc, 6, legend = 17))
    S(plot_direction_prob_maps(map, cfg$key, sc, fac, ncol = nc), "fig03b_direction_probability", 183, mapH(nr, nc, 16))
    hs <- plot_hotspot_maps(map, cfg$key, sc, fac, ncol = nc)
    if (!is.null(hs)) S(hs, "fig04_hotspots_Gi_star", 183, mapH(nr, nc, 14))
  }
  # 5-6 STVPI
  sv <- read_stvpi(res)
  S(plot_stvpi_facets(sv, ncol = 2), "fig05_STVPI_faceted", 183, 40 + 10 * length(fac))
  if (any(grepl("^time\\.", sv$effect))) S(plot_stvpi_stacked(sv), "fig06_STVPI_stacked", 120, 18 + 6 * length(fac))
  # 7-8 fit and predictions
  lp <- res$local.prediction; typ <- cfg$type
  S(plot_prediction_accuracy(lp, typ, logaxes = isTRUE(cfg$logaxes)), "fig07_prediction_accuracy", 89, 80)
  if (isTRUE(cfg$no_maps) && !is.null(cfg$time_col)) {
    S(plot_prediction_tiles(lp, cfg$key, cfg$time_col, labs_map, legend_title = cfg$pred_label, time_labels = cfg$time_labels), "fig08_prediction_tiles", 140, 110)
  } else if (!is.null(cfg$time_col) && cfg$time_col %in% names(lp)) {
    tm <- cfg$pred_times; ncp <- min(3, length(tm))
    p <- plot_prediction_maps(map, cfg$key, lp, cfg$time_col, tm, "predict_y", ncol = ncp, legend_title = cfg$pred_label)
    if (!is.null(cfg$time_labels)) p$data$time <- factor(cfg$time_labels[as.character(p$data$time)], levels = cfg$time_labels[as.character(tm)])
    S(p, "fig08_prediction_maps", 183, mapH(ceiling(length(tm) / ncp), ncp, 18))
  } else {
    S(plot_map_classed(map, cfg$key, data.frame(key = lp[[cfg$key]], value = lp$predict_y), NULL, k = 7, legend_title = cfg$pred_label), "fig08_prediction_map", 120, round(R$asp * 95 + 10))
  }
  invisible(res)
}

17  排错与常见问题

现象怎么办
双击后窗口黑一会儿正常，程序在启动。不要反复双击。
地图读取失败少选了文件：.shp .dbf .shx .prj（和 .cpg）要一次全选。
数据检查日志里有 Error，最后是 Success正常的检查过程信息，以卡片标题为准。
结果画到地图上看起来错位检查提示“已自动重排”后仍选了“原始数据”。改选“检查后数据”重跑。
下拉框里没有我的列载入的不是这张表（例如载入了宽表而不是转换后的长表）。重新载入后再选。
转换后的 CSV 用 Excel 打开乱码下载时选 Excel xlsx。
运行失败：Loop 0 is not valid: Edge 0 crosses edge …地图里有自相交的多边形。见案例 1 的修复步骤。
窗口一直灰着、显示“正在运行”大模型要多等一会儿（案例 6 约 ≈ 17 分钟）。任务管理器里 CPU 占用高、内存在变 = 仍在计算；若长时间没有任何占用而窗口不更新，关闭软件后重开。
只选了一个 X 就报错至少需要 2 个 X。
eff 或 DIC 是负数是该数据在该设置下的真实输出，如实报告，由使用者判断（见案例 4b）。
k 近邻矩阵报错或没有输出官方说明的已知局限；改用默认 QUEEN 矩阵或其他矩阵。
数字和本手册略有不同数值计算的正常波动，重复运行第 3–4 位有效数字可能不同。

17.1  好习惯

  1. 程序、数据、地图、结果全部用英文路径。
  2. 一个研究一个文件夹：表格、地图、结果放一起；原始数据不覆盖，转换后的文件另起名。
  3. 从小做起：先用 2–3 个完整的 X 跑通，再加变量。
  4. 每次跑完立刻下载全部表格，并在旁边记下设置（Y、X 及顺序、类型、时间、空间、标准化、矩阵、线程、软件版本、日期）——结果表本身不保存这些。
